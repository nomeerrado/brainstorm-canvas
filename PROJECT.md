# Brainstorm Canvas

Canvas web para brainstorm e diagramação, single-file (`index.html`) com React via CDN + Babel standalone.

## Funcionalidades

- **Ferramentas**: seleção, texto, retângulo, elipse, seta, traço livre, grupo
- **Paleta** de 8 cores e 4 espessuras de linha
- **Tamanho de fonte** ajustável para textos (A−/A+)
- **Resize** de objetos via alças nos cantos/lados (não aplicável a texto)
- **Navegação**: pan com Espaço/botão do meio, zoom via scroll ou Ctrl +/−
- **Minimapa** com clique/arraste para reposicionar
- **Histórico** com Ctrl+Z (até 50 ações)
- **Multi-seleção** por shift+clique ou retângulo de seleção
- **Exportar** em JSON ou PNG

## Atalhos

| Tecla | Ação |
|---|---|
| V / T / R / E / A / F / G | Selecionar / Texto / Retângulo / Elipse / Seta / Livre / Grupo |
| Ctrl+Z | Desfazer |
| Del | Deletar seleção |
| Esc | Desselecionar |
| Home | Centralizar canvas |
| Espaço+drag | Navegar |
| Ctrl + / − / 0 | Zoom in / out / reset |

## Como rodar

Abra `index.html` em qualquer navegador moderno — sem build, sem dependências locais.
